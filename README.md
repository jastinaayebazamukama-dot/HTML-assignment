# MUST Portal Login Interface

This project recreates the login and create account interface of the
Mbarara University of Science and Technology (MUST) online application portal.

## Features
- Login page with email and password fields
- Show/hide password button
- Create Account pop-up with surname, other names, phone number and email fields

## Files
- login.html - the login page and the Create Account pop-up
- style.css - the styling
- logo.png - the MUST logo

## Built with
HTML, CSS and JavaScript

## How to run
Download the files, keep them in the same folder, and open login.html in a web browser.
